✨ Project Overview
TimeBank is a revolutionary, student-centric platform developed by Team SkillUp at Graphic Era Hill University (GEHU). Our mission is to promote skill-sharing and community collaboration on campus by using time—not money—as the primary currency.

The core concept is simple: Students exchange services based on the time spent. One hour of service equals one time credit. This credit can then be redeemed for any other service on the platform.

Our Slogan: "Trade Your Time, Not Money." This platform aims to make student support and skill development accessible to everyone, regardless of their financial status.

💡 The Problem We're Solving
Campus life presents several challenges where students need help but face barriers:

Financial Barrier: Paying for small tutoring sessions, errands, or creative services can add up.

Skill Underutilization: Many students have valuable skills but lack an easy, equitable way to exchange them for services they need.

Access & Mobility: PWD candidates often struggle with mobility or finding immediate, accessible assistance for basic tasks.

🤝 Social Impact: Focusing on PWD Candidates
This platform is uniquely designed to be an asset for Persons with Disabilities (PWD), promoting true inclusion and breaking down barriers to access:

Accessible Errand Running: PWD candidates can easily spend time credits to request help with mobility-dependent tasks like printing documents, carrying books, or quick pickups from the library or hostel.

Equal Value for Skills: The platform ensures that a PWD candidate's academic or creative skill (e.g., coding, editing, tutoring) holds the exact same value as a physical errand run by someone else. Time is the great equalizer.

Zero Financial Strain: Since time credits are earned by sharing skills, PWD students can receive necessary physical support without any out-of-pocket expenses.

Fostering a Helper Community: It encourages non-PWD students to actively contribute to the community by easily offering accessible support services.

🛠️ Technology Used (Prototype Focus)
This project was successfully built within the 24-hour hackathon limit, focusing on rapid development and maximum accessibility:

Frontend Core: Vanilla HTML, CSS, and JavaScript were used to ensure an extremely lightweight, fast, and cross-browser-compatible user experience.

Cross-Platform Design: The entire website is designed to be fully responsive, ensuring a seamless user experience across all devices, including Android and iOS mobile platforms.

Database & Logic: We implemented a Demo Database (e.g., local storage or a simple JSON structure) to showcase the core functionality of the Time Credit System and user profiles during the prototype demonstration.

Future Scalability: For future rapid deployment and full-scale functionality (post-hackathon), we have prioritized its compatibility with modern stacks like Flutter and Firebase to enable a true cross-platform mobile app experience.
